# Screen Vision

Плагин даёт Астре **зрение**: когда вы спрашиваете про то, что видно на экране
(«что это за машина?», «что написано в этой ошибке?», «прочитай эту страницу»),
Астра делает скриншот и отвечает с помощью модели, которая понимает изображения.

Работает с любым **OpenAI-совместимым** endpoint — облачным или локальным.

## Настройка

После установки откройте **Настройки Astra → Screen Vision** (панель внизу
настроек) и заполните три поля:

| Поле | Что это | Пример |
|------|---------|--------|
| **API Base URL** | OpenAI-совместимый endpoint | `https://api.deepseek.com/v1`, `https://api.openai.com/v1`, `http://localhost:11434/v1` (Ollama) |
| **API Key** | Ключ доступа | Оставьте пустым для локальных endpoint (Ollama) |
| **Vision model** | Модель, которая принимает картинки | `gpt-4o`, `qwen2.5-vl`, `llava` |

> Зрение работает, только если указанная модель сама умеет принимать изображения.
> У DeepSeek стандартный API (`deepseek-chat`) текстовый — для зрения через DeepSeek
> нужна vision-модель (например, локальная `qwen2.5-vl` или `llava` через Ollama).

## Как это работает

Плагин добавляет один инструмент — `look_at_screen`. Ассистент сам вызывает его,
когда вопрос относится к тому, что на экране. Инструмент:

1. делает скриншот основного монитора;
2. отправляет его вместе с вопросом в настроенную модель;
3. возвращает ответ модели в чат.

## Требования

- Python 3.10+.
- Для захвата экрана: X11 (Windows работает из коробки; на Wayland захват может
  быть недоступен).
